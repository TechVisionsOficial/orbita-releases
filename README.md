# Órbita — instaladores

O **Órbita** é o programa de prospecção de clientes da [Tech Visions](https://www.techvisions.com.br): encontra empresas por ramo, cidade, bairro ou CEP, mostra quem não tem site, junta os contatos e organiza o acompanhamento em um funil.

Este repositório guarda **só os instaladores** das versões publicadas. O código é privado.

## Baixar

Na página da [versão mais recente](https://github.com/TechVisionsOficial/orbita-releases/releases/latest):

| Computador | Arquivo |
|---|---|
| Mac com Apple Silicon (M1, M2, M3, M4…) | `Orbita-x.y.z-mac-arm64.dmg` |
| Mac com processador Intel | `Orbita-x.y.z-mac-x64.dmg` |
| Windows 10 ou 11 | `Orbita-Setup-x.y.z.exe` |

Para usar, é preciso uma **licença**: entre com a conta Google cadastrada pela sua empresa ou pela Tech Visions.

## Instalação

- **Mac:** abra o `.dmg` e arraste o Órbita para Aplicativos. Na primeira vez, se o macOS bloquear, abra *Ajustes do Sistema → Privacidade e Segurança* e clique em **Abrir mesmo assim**.
- **Windows:** execute o instalador. Se aparecer “O Windows protegeu o computador”, clique em **Mais informações → Executar assim mesmo**.

O Órbita procura atualizações sozinho e avisa quando houver uma versão nova.
